## Introducción
Este es mi manual personal de comandos básicos de Git. Lo he preparado para tener a mano las instrucciones, esta realizado de forma clara y visual.

### git clone
**Descripción:** Copia un repositorio remoto a tu equipo.  

### git add
**Descripción:** Añade archivos al área de preparación (staging area) para incluirlos en el próximo commit.

### git commit
**Descripción:** Guarda los cambios preparados en el historial con un mensaje descriptivo.

### git log
**Descripción:** Muestra el historial de commits. 

### git checkout
**Descripción:** Cambia entre ramas o restaura archivos a versiones anteriores. Cambiar a una rama existente:

### git branch
**Descripción:** Lista, crea o elimina ramas.

### git push
**Descripción:** Envía los commits locales al repositorio remoto.

### git pull
**Descripción:** Descarga cambios del remoto y los fusiona en la rama actual.

### git merge
**Descripción:** Fusiona otra rama dentro de la rama actual.
